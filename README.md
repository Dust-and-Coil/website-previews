# website-previews

Static Jekyll builds for open pull requests on [Dust-and-Coil/website](https://github.com/Dust-and-Coil/website).

Each PR publishes to `pr-<number>/`, e.g. https://dust-and-coil.github.io/website-previews/pr-2/

Do not put a CNAME here — production stays on dustandcoil.com via the main website repo.
